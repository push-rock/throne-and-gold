# 王座与黄金 · Throne & Gold

一个 DnD 题材的文字放置/决策经营游戏 DEMO。**单文件、零依赖、离线可玩**。

## 怎么玩

下载 `王座与黄金.html`，双击用浏览器打开即可（无需联网、无需安装）。

- 每局选择 **种族 / 职业 / 阵营 / 人生路线**（王座线：影响力问鼎 vs 黄金线：金币垄断），路线一局锁定，重开才有新人生
- 时间自动流动（1 日 = 3 秒，可暂停/调速），你负责决策：处理底栏事件卡、点地图节点发起行动、在左栏经营产业与军团
- 所有判定都是 D&D 式 `d20 + 修正 vs DC`：骰 20 大成功，骰 1 大失败，DC 与修正全部前置可见
- 从个人抉择一路走到集体抉择：协会 → 领地 → 兵团 → 王冠（或 店铺 → 行会 → 庄园 → 财团 → 国债）
- 多种结局：贤明之王 / 铁血霸主 / 屠龙者 / 无冕富王 / 垄断者 / 债主之王……或死于龙息、或碌碌一生

## 文件

| 文件 | 说明 |

| `王座与黄金.html` | 游戏本体（全部逻辑内联在这一个文件里） |
| `游戏策划书.md` | 设计文档（双线系统、职业/种族表、事件池、结局设计） |

## 存档

进度自动保存在浏览器 localStorage（key `dnd_throne_gold_v1`）。
游戏内支持导出/导入存档文本，换机/分享进度用。
